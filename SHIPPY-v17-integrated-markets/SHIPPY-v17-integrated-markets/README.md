# SHIPPY v17 — Integrated Markets Edition

SHIPPY is an English-language browser game and physical commodity trading simulator built around a realistic interactive globe.

## What is new in v17

- AI rival trading desks now compete for the same physical tenders.
- Competitive pressure changes negotiation probability, margin and opportunity availability.
- Tenders can be awarded to rivals when the player waits too long.
- Five market regimes drive volatility, margin, capital requirements and freight conditions.
- New Competitive Intelligence module with live tender pressure and an award tape.
- Ten persistent career achievements linked to execution, risk, growth and tender performance.
- Improved English cleanup and updated PWA cache.

## Run locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Deploy to Vercel

Upload every file in this folder to the root of the GitHub repository connected to Vercel. Use **Other** as the framework preset and leave Build Command and Output Directory empty.

Career data remains stored locally in the browser. Authentication, cloud saves and a real online multiplayer leaderboard require a backend.


## v17 highlights
- Seasonal physical demand by commodity and month
- Pricing formulas with explicit basis and buyer-option risk
- Board strategy doctrines with measurable economic effects
- Trade-credit insurance and receivables factoring
- Warehouse optionality for flexible-delivery cargoes
- Trading-house enterprise valuation and board mandates

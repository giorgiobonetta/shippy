# World of Trade Android project

Open this folder directly in Android Studio.

- Application ID: `com.worldoftrade.game`
- Minimum Android: 7.0 / API 24
- Target Android: API 36
- Orientation: landscape
- Web game assets: `app/src/main/assets/www`

The project intentionally keeps the web assets inside the APK so the game can start without contacting Vercel.

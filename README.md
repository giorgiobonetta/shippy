# World of Trade v33

World of Trade is a browser-based physical commodity trading and trading-house expansion simulator.

## Career progression

A new player begins in Geneva with a small balance sheet, one copper supplier in Tallinn and one industrial buyer in Brescia. New commodities and countries unlock with experience levels. More resource-rich and capital-intensive markets require higher levels.

## Global risk engine

The simulation includes geopolitical conflict, sanctions, export controls, recessions, interest-rate shocks, dollar funding stress, hurricanes, drought, frost, low river levels, cyclones, strikes, cyberattacks, piracy, credit downgrades, currency controls, environmental regulation and compliance events. These risks affect P&L, prices, freight, financing, collateral, credit and delivery.

## Deployment

Upload all files in this folder directly to the root of the existing GitHub repository. Do not upload the ZIP itself. The flat package is designed to work with GitHub browser uploads.
